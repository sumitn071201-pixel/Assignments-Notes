## 🧩 Shared Views

### 1. **_EmpPartialView.cshtml**
```csharp
@model _08Demo_Bootstrap_Layout_PartialView.Models.Emp

<tr>
    <td>@Model.Id</td>
    <td>@Model.Name</td>
    <td>@Model.Address</td>
</tr>
```
- Renders a single employee row inside a table.
- Called from `Views/Home/Index.cshtml` using:
  ```csharp
  <partial name="_EmpPartialView" model="emp" />
  ```
- Keeps your table rendering modular and reusable.

---

### 2. **_ProductPartialView.cshtml**
```csharp
@model _08Demo_Bootstrap_Layout_PartialView.Models.Product

<div class="card" style="width: 18rem;">
    <img src="@(Model.Image)" asp-append-version=true class="card-img-top" alt="product info">
    <div class="card-body">
        <h5 class="card-title">@Model.Name</h5>
        <p class="card-text">@Model.Description</p>
        <p class="card-text">@Model.Price</p>
        <a href="#" class="btn btn-primary">Add To cart OR Deatils</a>
    </div>
</div>
```
- Renders a single product card using Bootstrap’s **card component**.
- Called from `Views/Home/ProductData.cshtml` and `Views/Home/PData.cshtml`.
- Uses `asp-append-version=true` → ensures cache-busting for images when they change.

---

### 3. **_Layout.cshtml**
- Default layout (set in `_ViewStart.cshtml`).
- Provides:
  - **Header** with logo and site name.
  - **Navigation bar** with links to Home, About, Contact, Courses, Product Data.
  - **Main content area** → `@RenderBody()` injects the view’s content.
  - **Footer** with copyright.
  - Bootstrap CSS/JS references.
- Example flow:  
  Request `/Home/Index` → `HomeController.Index()` → `Views/Home/Index.cshtml` → wrapped inside `_Layout.cshtml`.

---

### 4. **_Layout2.cshtml**
- Alternative layout used by some views (like `Demo/GetProducts`).
- Similar structure but different styling:
  - Orange header, forest green footer.
  - Navigation includes a link to `/Demo/GetProducts` (Shopping).
- Example flow:  
  Request `/Demo/GetProducts` → `DemoController.GetProducts()` → `Views/Demo/GetProducts.cshtml` → wrapped inside `_Layout2.cshtml`.

---

## 📂 Razor Infrastructure

### **_ViewImports.cshtml**
```csharp
@addTagHelper *, Microsoft.AspNetCore.Mvc.TagHelpers
```
- Makes ASP.NET Core **Tag Helpers** available in all views.
- Example: `asp-append-version`, `asp-action`, `asp-controller`, `asp-route-id`.

### **_ViewStart.cshtml**
```csharp
@{
    Layout = "_Layout";
}
```
- Sets `_Layout.cshtml` as the **default layout** for all views.
- Individual views can override this by setting `Layout = "~/Views/Shared/_Layout2.cshtml";`.

## 🔄 Full Execution Flow (Putting It All Together)

1. **Request comes in** → Routing decides controller/action.
2. **Controller executes** → Prepares data (Emp list, Product list, ProductViewModel).
3. **View selected** → Razor view (`Index.cshtml`, `GetProducts.cshtml`, etc.) is chosen.
4. **Model passed to view** → Strongly typed with `@model`.
5. **Partial views render** → `_EmpPartialView` or `_ProductPartialView` generate reusable UI pieces.
6. **Layout wraps view** → `_Layout.cshtml` or `_Layout2.cshtml` injects shared header, nav, footer, Bootstrap.
7. **Static files served** → Images from `wwwroot/images`, Bootstrap CSS/JS from `wwwroot/bootstrap`.
8. **Final HTML response** → Sent to browser.

---

## ⚡ Key Insights
- **Layouts** = global structure (header, nav, footer, Bootstrap).
- **Partial Views** = reusable components (employee rows, product cards).
- **_ViewStart** = default layout for all views.
- **_ViewImports** = global namespaces and tag helpers.
- **Bootstrap** = styling and responsiveness.
- **wwwroot** = static assets (images, CSS, JS).
